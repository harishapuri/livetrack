# FORM 18

**THE PATENTS ACT, 1970 (39 of 1970)**
**AND THE PATENTS RULES, 2003**

**REQUEST FOR EXAMINATION OF APPLICATION FOR PATENT**
**(See section 11B and rule 24B)**

---

**DO NOT FILE THIS FORM WITH THE APPLICATION UNLESS YOU INTEND TO START EXAMINATION AND PAY THE EXAMINATION FEE.**

Filing Form 18 asks the Patent Office to examine the application. It does not grant a patent. The request is due within the statutory period, commonly 48 months from the filing date when there is no earlier priority. Confirm that period and the fee on ipindia.gov.in on the day you file this form. If the request is not filed in time, the application is treated as withdrawn.

A request for expedited examination (Form 18A) is a different form, with eligibility conditions and a higher fee. This draft is ordinary examination only.
